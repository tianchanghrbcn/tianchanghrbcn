### Current Research

I am currently working on **TRACE: An Empirical Study of How Data Cleaning Affects Unsupervised Clustering**.

This project studies how data cleaning affects unsupervised clustering beyond final outcome scores. It traces the effect of cleaning through data rewriting, process-level signals, outcome benefits, and hyperparameter shifts, with the goal of making data-quality interventions more observable, reproducible, and task-aware.

### Selected Project

**TRACE — Data Cleaning and Unsupervised Clustering**

- Built a unified empirical pipeline for studying cleaning–clustering interactions.
- Evaluated multiple data cleaning methods and clustering algorithms under shared experimental settings.
- Analyzed how data repair changes downstream clustering behavior through intermediate process signals.
- Developed reproducible experiment scripts, analysis outputs, and artifact documentation.
